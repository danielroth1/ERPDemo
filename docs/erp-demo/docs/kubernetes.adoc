== Overview

Kubernetes is the platform used to run the system as containers in a cluster. If you are new to it, remember four building blocks:

* a node is a machine in the cluster
* a pod is one running application unit
* a service gives stable networking to pods
* an ingress or gateway exposes traffic into the cluster

This repository uses a shared base plus overlays for local development, a private k3s server, and Azure AKS.

== Local Kubernetes

=== Introduction

The local overlay is useful when you want to validate manifests, service discovery, and cluster-style networking on your workstation.

=== Setup Example

[source,bash]
----
kubectl apply -k infrastructure/k8s/local
----

You can also use the existing development helpers.

[source,text]
----
k8s: deploy-local
k8s: port-forward-frontend
k8s: port-forward-gateway
----

Or use Skaffold for a faster inner loop.

[source,bash]
----
skaffold dev
----

=== Advantages

* Good for validating manifests and service-to-service behavior.
* Closer to production than plain Docker Compose.

=== Disadvantages

* Still not identical to a managed cloud cluster.
* Cluster networking and image build loops add complexity.
